# Deep RL Explorer

Deep RL Explorer est une application web interactive créée pour présenter les concepts fondamentaux du Deep Reinforcement Learning à travers des animations, des schémas explicatifs, une simulation GridWorld et des visualisations pédagogiques.

## Objectif

L’objectif est de rendre le Deep Reinforcement Learning plus compréhensible grâce à une approche visuelle et interactive.

## Fonctionnalités

- Concepts interactifs du Reinforcement Learning
- Schéma animé Agent-Environnement
- Simulation GridWorld avec score, obstacles, piège et objectif
- Explication interactive du Q-Learning
- Graphique d’apprentissage progressif
- Visualisation du Deep Q-Network
- Comparaison RL classique vs Deep RL
- Applications réelles du Deep Reinforcement Learning
- Design responsive pour ordinateur et téléphone

## Technologies

- React
- Vite
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide React

## Installation locale

```bash
npm install
```

## Lancement local

```bash
npm run dev
```

Avec la configuration GitHub Pages, l’application est servie localement sur:

```text
http://localhost:5173/DeepRL-Explorer/
```

## Build

```bash
npm run build
```

## Prévisualisation du build

```bash
npm run preview
```

## Déploiement GitHub Pages plus tard

Le projet est configuré avec:

```js
base: '/DeepRL-Explorer/'
```

Étapes recommandées après validation:

1. Créer le repository GitHub `DeepRL-Explorer` dans le compte `Younlam9`.
2. Initialiser Git si nécessaire et pousser le projet sur GitHub.
3. Exécuter `npm run build`.
4. Publier le dossier `dist` via GitHub Pages ou configurer une GitHub Action de déploiement.
5. Vérifier le lien final:

